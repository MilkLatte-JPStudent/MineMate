# MineMate (Minecraft AI Bot)

MineMateは、Googleの **Gemini 3.1 Flash / Pro** を用いた、完全に自律的なMinecraft AI Botプロジェクトです。視覚・聴覚・チャット・各種センサ情報を組み合わせて世界を認識し、自分で考え、自分でJavaScriptのスクリプトを組んで行動します。

## 主な特徴 (Features)

* **デュアルエージェント・アーキテクチャ**
  * **Low-Level Agent (Gemini 3.1 Flash):** 常に映像と音を監視し、反射的な行動やコード生成を超高速で行うメインループを担います。
  * **High-Level Agent (Gemini 3.1 Pro):** 複雑な計画が必要な場合（`Execute: "Thinking"`）にのみ呼び出され、Google検索や超大型タスクツリー（サバイバル、建築、RTA、レッドストーンなど）を駆使して長期的な行動指針を決定します。

* **視覚と聴覚のマルチモーダル認識**
  * `mineflayer-viewer` の映像をヘッドレスブラウザ(Puppeteer)経由で7fpsでキャプチャし、画質を意図的に下げる（軽量化する）ことで高速な視覚情報としてAIに渡します。
  * `soundEffectHeard` イベントを計算し、音の鳴った方向ベクトルや距離をテキスト化して動画フレームと同期させて提供します。

* **自律的なJSスクプレクト生成と非同期実行**
  * AIは単一のコマンドを返すのではなく、`mmskills` という独自API群と標準JS構文（for, ifなど）を組み合わせた**「丸ごと一本のJavaScriptコード」**を生成します。
  * 生成されたコードはセキュアなVMサンドボックス内で非同期（バックグラウンド）実行されるため、スクリプト実行中であってもAIの監視ループは止まらず、並行して状況判断を行えます（干渉を避けるための `Execute: "None"` 機能付き）。

* **緊急モード (Emergency Mode)**
  * 平時は1.2秒間隔でAIが状況をポーリングしますが、HPの減少や敵対モブの接近を検知すると**0.2秒間隔**の超高速ポーリングに自動で切り替わります。
  * AI自身の判断により、コードやJSON上から手動で緊急モードを発動（`on`, `off`, `toggle`, `time`指定）させることも可能です。

* **自己学習モード (Learning Mode)**
  * AIが自ら「成功した体験」や「効果的だった戦略」を専用のJSONファイル（`task_tree.ai_experience.json`）に書き込む権限を持っています。
  * `config.json` で学習モードが有効になっている場合、高レベルAIはその過去の成功体験を読み込み、将来のタスク解決に再利用します。

## ディレクトリ構成と仕様

* `index.js` - プロジェクトのメインエントリ。Botの接続、ビューワの起動、チャット/音の監視を行います。
* `config.json` - 学習モードのオンオフなどを設定します。
* `ai/`
  * `lowLevelAgent.js` - Flashモデルによるメインの監視・実行ループ。直近55件のチャットログや緊急モード制御が含まれます。
  * `highLevelAgent.js` - Proモデルによる思考エージェント。Google検索やタスクツリー、過去の記憶を読み込みます。
* `vision/`
  * `capture.js` - Puppeteerを利用したスクリーンショットの連続撮影を行います。
* `skills/`
  * `executor.js` - AIが生成したJSコードを実行するサンドボックス環境。
  * `tree.json` - AIに各スキルの使い方を教えるためのマニュアルファイル。
  * `task_tree.json` - Minecraftの各分野（サバイバル、PVP、レッドストーン等）の知識を網羅した高レベル思考用データベース。
  * `task_tree.ai_experience.json` - AIが自己保存する学習メモリ（動的に更新されます）。

## 使い方 (Usage)

### 1. 動作要件
* Node.js (v18以降を推奨)
* Minecraft サーバー (1.8 ~ 1.20系。mineflayerのサポートバージョンに準拠)

### 2. インストール
```bash
npm install
```

### 3. 環境変数の設定
プロジェクトのルートに `.env` ファイルを作成（または編集）し、以下の情報を入力してください。

```ini
GEMINI_API_KEY=あなたのGemini_APIキーを入力
MC_HOST=localhost       # マイクラサーバーのIP
MC_PORT=25565           # マイクラサーバーのポート
MC_USERNAME=MineMate    # Botの名前
```

### 4. 起動
Minecraftサーバーを立ち上げた状態で、以下のコマンドを実行します。

```bash
node index.js
```

Botがサーバーにログインすると、バックグラウンドでビューワが起動し、AIが世界を認識して自律的に動き始めます！
