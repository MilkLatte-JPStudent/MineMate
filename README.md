# MineMate (Minecraft AI Bot)

MineMateは、Googleの **Gemini 3.1 Flash / Pro** を用いた、完全に自律的なMinecraft AI Botプロジェクトです。視覚・聴覚・チャット・各種センサ情報を組み合わせて世界を認識し、自分で考え、自分でJavaScriptのスクリプトを組んで行動します。

## 主な特徴 (Features)

* **デュアルエージェント・アーキテクチャ**
  * **Low-Level Agent (Gemini 3.1 Flash):** 常に映像と音を監視し、反射的な行動やコード生成を超高速で行うメインループを担います。
  * **High-Level Agent (Gemini 3.1 Pro):** 複雑な計画が必要な場合（`Execute: "Thinking"`）や記憶の視覚的想起（`Execute: "FlashBack"`）の際に呼び出され、長期的な行動指針を決定します。

* **視覚と聴覚のマルチモーダル認識**
  * `mineflayer-viewer` の映像をヘッドレスブラウザ(Puppeteer)経由でキャプチャし、視覚情報としてAIに渡します。
  * `soundEffectHeard` イベントを利用し、音の鳴った方向や距離を計算して同期提供します。

* **セキュアな自律JS実行サンドボックス (AST検証 + Worker隔離)**
  * AIは単一のコマンドではなく、`mmskills` という独自API群と標準JS構文を組み合わせた**「丸ごと一本のJavaScriptコード」**を生成します。
  * 生成されたコードは実行前にAST（抽象構文木）による静的解析が行われ、危険なグローバル変数（`process`等）へのアクセスが弾かれます。
  * さらに、**隔離されたWorkerスレッド (メモリ制限付き)** 上で実行されるため、万が一AIが無限ループや巨大配列でメモリを食い潰しても、メインプロセスごとクラッシュするのを防ぎ、自動で自己修復（エラーをプロンプトに還元）します。メインのBotプロセスとの通信は安全なIPCプロキシを通して行われます。

* **長期記憶とベクトル検索システム (LongMemory & FlashBack)**
  * **LongMemory:** AIが「記録すべきだ」と判断した瞬間、高画質スクショとともにテキスト情報を保存します。保存したタイトルはGemini APIの`text-embedding-004`で数値ベクトル化され、後から曖昧な言葉でも**コサイン類似度を使ったベクトル検索**で素早く記憶を引き出せます。
  * **FlashBack:** より強力な記憶想起が必要な場合、保存された全てのテキストと**スクショ画像そのもの**をGemini 3.1 Proに読み込ませ、視覚情報から詳細な道順や座標を思い出させることができます。

* **高度なクラフト・UI操作 (Craft & Window Control)**
  * `mineflayer` の内部APIをプロキシし、アイテムのクラフト（2x2/3x3）、チェスト等のUI検知、特定のインベントリスロットへの左クリック・右クリック・Shiftクリック操作などをセキュア環境から自由に制御できます。

* **緊急モードと内省機能 (Emergency & Thought)**
  * 平時は1.2秒間隔ですが、危機的状況では**0.2秒間隔**の超高速ポーリングに自動・手動で切り替わります。
  * AI自身が毎ループ `Thought` キーを使って「自分がどうしてその行動をしたのか」を文脈にメモ書きとして残すことで、一貫した行動と思考を維持します。

## ディレクトリ構成と仕様

* `index.js` - プロジェクトのメインエントリ。Botの接続、ビューワの起動、チャット/音の監視を行います。
* `config.json` - 学習モードのオンオフなどを設定します。
* `ai/`
  * `lowLevelAgent.js` - Flashモデルによるメインの監視・実行ループ。内省(Thought)、ベクトル検索、緊急モード制御を担います。
  * `highLevelAgent.js` - Proモデルによる思考エージェント。Google検索やタスクツリー、FlashBackのマルチモーダル記憶処理を担います。
* `vision/`
  * `capture.js` - Puppeteerを利用したスクリーンショットの連続撮影や、高画質画像の保存を行います。
* `skills/`
  * `executor.js` - メインスレッド側のIPC通信インターフェースとBot制御。
  * `worker.js` - メモリ制限された隔離VM（Workerスレッド）。
  * `validator.js` - 生成されたコードのAST（抽象構文木）セキュリティ検証。
  * `LongMemory.json` / `task_tree.spatial_memory.json` - AIのベクトル記憶や空間記憶を保存するデータベース。
  * `tree.json` - AIに各スキルの使い方を教えるためのマニュアルファイル。
  * `task_tree.json` - Minecraftの各分野の知識を網羅した高レベル思考用データベース。

## 使い方 (Usage)

### 1. 動作要件
* Node.js (v18以降を推奨)
* Minecraft サーバー (1.8 ~ 1.20系。mineflayerのサポートバージョンに準拠)

### 2. インストール
```bash
npm install
```

### 3. 環境変数の設定
プロジェクトのルートに `.env` ファイルを作成（または編集）し、以下の情報を入力してください。

```ini
GEMINI_API_KEY=あなたのGemini_APIキーを入力
MC_HOST=localhost       # マイクラサーバーのIP
MC_PORT=25565           # マイクラサーバーのポート
MC_USERNAME=MineMate    # Botの名前
```

### 4. 起動
Minecraftサーバーを立ち上げた状態で、以下のコマンドを実行します。

```bash
node index.js
```

Botがサーバーにログインすると、バックグラウンドでビューワが起動し、AIが世界を認識して自律的に動き始めます！
